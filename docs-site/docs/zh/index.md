# MIMO FMCW 雷达仿真器

本站用于说明基于三角面片网格的 MIMO FMCW 雷达仿真器，包括处理流程、核心模块和文档工程结构。

仿真器会读取三角面片 3D 模型，筛选朝向雷达且未被遮挡的可见面，将可见面近似为散射单元，合成原始雷达数据，并输出距离、速度和角度三次 FFT 结果。

## 本站内容

- 如何安装和运行仿真器。
- mesh 到雷达数据的处理链路。
- 各核心模块的职责。
- 双语 MkDocs 文档站点的组织方式。
